# proyecto-newspaper
Proyecto para newspaper UAEH 

Para programar el STM32 F411CEU6 se necesitan dos aplicaciones:
 - STM32CubeMX: Sirve para configurar el microcontrolador incluyendo sus pines para la comunicación y los periféricos.
 - STM32CubeIDE: Aquí se escribe toda la programación;
<img width="317" height="551" alt="image" src="https://github.com/user-attachments/assets/1b3a00ab-edcf-4d69-9c0a-e272b9998ab6" />
- en proyecto>Core>Src>main.c Se programa casi todo,
- en proyecto>Core>Inc Se pueden escribir "librerias", lo que nosotros usaremos para hacer operaciones matemáticas.
  
*Descarga las ultimas versiones de los programas para no tener fallas.
